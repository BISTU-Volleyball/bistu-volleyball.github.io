北京信息科技大学教职工排球协会简介

排球协会是由学校一群热爱排球的教职工自愿组成的非营利性、群众性体育文化团体，隶属于北京信息科技大学工会委员会，致力于丰富教职工业余文化生活、推广排球运动、弘扬团队精神。

排球协会成立于2025年6月3日，目前协会会员已达197名；连续三年联合体育部举办教职工气排球培训班，培训教职工累计百余人次；排协会员参与热情空前高涨，日常训练赛由原定的每周两次改为每个工作日都举行。

我们走过的路

  1. 2024年5月，协助组织学校第一期教职工气排球培训班，共14位老师参训，激发了教职工的排球热情、为学校排球运动奠定了基础；

  2. 2025年3月：组织20余名教师参加第二期教职工气排球兴趣培训班，有效提升了教职工气排球技术，为师生排球赛奠定了坚实的基础；

    {% for i in (1..2) %}{% endfor %}

  3. 2025年3月：组织14名教师参加第二届“热血高校、燃爆校园”师生排球赛，展现出强烈的团队协作意愿与竞技热情，不仅培养了教职工的运动习惯，更推动了排球运动在学校快速升温，催生了成立正式排球协会的集体诉求；

    {% for i in (1..2) %}{% endfor %}

  4. 2025年5月12日，协助成立外国语学院排球队、联合外国语学院举办首届教职工气排球友谊赛；

  5. 2025年5月26日，联合体育部、光电学院、计算机学院共同举办第三届“热血高校 燃爆校园”师生气排球联谊赛；

  6. 以原有气排球培训群为基础，通过校内通知、部门推荐等渠道扩大招募范围，6月初已累计吸引百余名教职工注册成为会员，涵盖教学、管理、教辅等多个部门，其中具备排球基础的会员占比达45%，形成了跨学科、多层次的人员结构。2025年6月3日，在校工会的指导下，召开了教职工排球协会成立大会，排协正式注册成立；

    {% for i in (1..3) %}{% endfor %}

  7. 2025年6月9日，联合理学院成功举办“理心悦动”气排球师生联谊赛；

  8. 2025年11月：举办2025年“排绽风采，师生聚力”师生气排球赛，共83人参赛（教职工73人、学生10人），此次比赛展现出较高的气排球竞技水平，在学校营造出良好的排球氛围，极大程度提高了排协的影响力和美誉度；

    {% for i in (1..7) %}{% endfor %}

  9. 2026年5月，协助组织学校第三期教职工气排球培训班。本期培训班全面优化升级，创新采用“基础班+提高班”双轨分层教学模式，精准适配不同运动基础教职工的学习需求，基础班28人、提高班15人参训，培训教职工累计百余人次。

    {% for i in (1..3) %}{% endfor %}

日常训练

排协每周由专业教练指导训练（包含气排球的基础教学与对抗赛），定期组织并参与校际联赛、全校师生排球赛等大型活动。

📍 活动地点：沙河校区体育馆
