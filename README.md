# 北京信息科技大学教职工排球协会网站

网址：https://bistu-volleyball.github.io/

- 日常发布内容请用网站上的「发布助手」：https://bistu-volleyball.github.io/publish/
- 管理员操作说明见 [使用说明.md](使用说明.md)
- 网站用 GitHub Pages 自带的 Jekyll 生成，无需服务器。站内链接都用相对路径，整个仓库可直接迁移到其他静态服务器（需先用 Jekyll 生成）。

目录：`_posts/` 已发布文章，`_pending/` 待审核投稿，`assets/posts/<文章编号>/` 文章的照片和视频，`publish/` 发布助手。
